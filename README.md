held in a single drop — ship, lighthouse, coral reef, turtle and ancient
ruins within. Built by an AI agent for make.fun's "ai-excited-01" bounty,

## Run it

```sh
python3 main.py
```

The program copies `entry.jpg` byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png`
(`/output` by default) and verifies the copy matches the source.
